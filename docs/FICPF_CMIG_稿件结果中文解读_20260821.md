# FICPF 稿件结果中文解读

## 当前主结论

FICPF 的正式五数据集宏平均 C-index 为 `0.7050`，高于同协议 matched VLSA 的 `0.6958`，平均提升 `+0.0092`，患者级配对 bootstrap 的 95% CI 为 `[0.0016, 0.0169]`。这说明主结论已经不是“某一个 fold 偶然变好”，而是在锁定协议下具有总体统计证据的跨数据集改进。

五个数据集的平均值都高于 matched VLSA 和原论文参考值，但证据强度不相同。BLCA 和 GBMLGG 的队列级置信区间排除零，是最强的两个结果。LUAD 五折全部正向，但样本波动使置信区间仍跨零。BRCA 几乎没有提升，UCEC 有小幅提升但不稳定。因此论文应写成“跨队列宏平均显著提高，并在所有队列保持非负平均结果”，不能写成“每个癌种都显著优于原方法”。

## 创新点如何成立

FICPF 的创新不在于简单增加 RNA-seq/CNV，而在于解决冻结病理模型与弱组学模型之间的尺度不一致和负迁移问题。组学单独预测的宏平均只有 `0.6273`，明显低于病理；直接把两个原始分数相加只提升 `+0.0014`。使用训练折 ECDF 对齐后，FICPF 比相同权重的未校准融合再提高 `+0.0078`，且置信区间排除零。这组消融是方法有效性的核心证据。

固定 `0.80/0.20` 权重也有明确作用。等权融合虽然在 BLCA 和 GBMLGG 更高，但会明显损害 BRCA 和 UCEC。保守组学权重牺牲了部分强组学队列的峰值，以换取跨癌种稳定性。参数敏感性显示 `alpha=0.10-0.30` 是平台区，而不是只有 `0.20` 一个点有效。

组学打乱实验进一步证明了患者级对应关系的重要性。BLCA、GBMLGG、LUAD 和 UCEC 的真实组学配对明显优于随机打乱；BRCA 不明显，与它在主结果中几乎没有增益一致。这个结果支持“组学提供患者特异互补信息”，而不是“融合只是对病理分数做随机平滑”。

## 必须诚实报告的限制

FICPF 改善了五个数据集的 IBS，使 D-calibration 通过折数从 `14/25` 增加到 `25/25`，并降低了 KM calibration error。但绝对时间 MAE 从 `25.23` 个月变差到 `29.89` 个月。因此当前方法更擅长患者风险排序和群体概率校准，不擅长精确预测个体生存月数。

组学损坏实验也存在队列差异。宏平均在中等缺失和噪声下仍高于病理，但 UCEC 因只有 123 个签名组学特征，在 50% 特征缺失或强噪声下会出现负迁移。论文应把显式病理回退作为实际部署策略，并将低覆盖队列的特征级脆弱性列为限制。

## 对二区投稿的意义

目前证据已经形成一条完整方法链：冻结强病理模型、训练折内组学读出、归纳式分布校准、保守融合、缺失模态回退、完整生存曲线重建，并配有外部多模态对照、组件消融、负对照、参数敏感性、鲁棒性、复杂度和随机种子稳定性。相较于此前大量只在单折或单 seed 上出现的小提升，这条主线更接近 CMIG 所要求的完整性。

它仍不是稳妥录用保证。最主要的短板是 BRCA 改进接近零、绝对时间 MAE 变差、当前完整 VLSA 主干没有多 seed 重训，以及实验仍限于 TCGA 回顾性队列。投稿时应把贡献定位为“无需联合深度重训的防泄漏稳健病理-组学融合”，而不是宣称在所有生存预测维度上全面领先。
