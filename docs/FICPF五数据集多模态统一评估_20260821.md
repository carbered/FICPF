# FICPF 五数据集多模态统一评估

## 评估目的

本次评估在相同患者、相同 outer 5-fold 和相同 CONCH patch 特征下，对 matched VLSA、MCAT-CONCH、CAT-TPL-CONCH 与 FICPF 进行统一比较。MCAT-CONCH 和 CAT-TPL-CONCH 使用 CAT-with-TPL 作者代码的锁定训练协议，即 seed 1、20 epoch、学习率 `1e-4`、梯度累积 16、加权采样、无早停和 raw last checkpoint。两项方法均属于 CONCH 适配复现，不等同于作者论文中的原始 RN50 实验。

## 指标与审计

全部模型使用 `SurvivalEVAL_mean_continuous_comparable_all_ties` 契约重新计算 C-index。显著性分析使用患者级、折内分层的配对 bootstrap，每项比较进行 5000 次重采样，五折差值取平均。宏平均 bootstrap 对五个数据集等权汇总。

下载包包含 50 个外部模型逐折预测文件和 50 个 split 文件。统一分析覆盖 2831 名唯一患者与 25 个 outer fold。四种方法的患者集合、生存时间和事件标签逐项一致，没有重复患者或非有限预测。作者日志与统一复算之间的最大 C-index 绝对差为 `0.000571`，差异仅来自 ties 处理契约，风险方向和预测读取均通过审计。

宏平均上，FICPF 相对三项参照的 95% CI 均排除零，`P(delta > 0)` 分别为 `0.9928`、`1.0000` 和 `0.9996`。数据集层面，FICPF 相对 matched VLSA 在 BLCA 和 GBMLGG 上达到名义显著；相对两项外部端到端融合基线在 BRCA 和 UCEC 上达到名义显著。上述区间没有进行多重比较校正，因此正式论文应区分预设的宏平均主比较与数据集级探索性比较。患者级 bootstrap 衡量固定模型下的测试患者抽样不确定性，不包含训练随机种子方差，不能被表述为已经完成多 seed 稳定性检验。

## 结果解释

BLCA 和 GBMLGG 提供了 FICPF 改善强病理 baseline 的主要性能证据。LUAD 五折均高于 matched VLSA，但数据集级区间仍跨零。BRCA 和 UCEC 相对 matched VLSA 只有小幅平均变化，不支持显著性能提升；它们主要说明端到端病理-组学训练发生负迁移时，FICPF 的冻结病理分支和训练折内校准能够保持原有性能。

MCAT-CONCH 和 CAT-TPL-CONCH 的宏平均均低于 matched VLSA，且差异的宏平均区间排除零。这不能被表述为所有多模态方法天然无效，而应解释为小事件生存队列中端到端联合训练存在明显不稳定性。CAT-TPL-CONCH 在 BLCA 和 GBMLGG 上仍优于 matched VLSA，说明它是部分队列中的有效强基线，而非失效实现。

## 结论与边界

统一评估支持将 FICPF 作为当前论文主线。它同时具备五数据集平均结果全部领先、宏平均相对 matched VLSA 接近一个 C-index 百分点、相对两项同输入多模态基线保持显著总体优势，以及完整的患者级可复核预测。

当前证据仍不能表述为五个数据集分别显著领先，也不能把 CONCH 适配结果冒充 MCAT 或 CAT-with-TPL 的原论文数字。FICPF 还存在个体 Mean-MAE 退化，正式论文必须与已经完成的 IBS、D-calibration 和 KM calibration 结果共同报告。下一阶段应集中完成方法消融、复杂度统计和论文图表，不再根据 outer test 结果搜索融合权重或数据集专属参数。

## 组件消融补充

五数据集组件消融进一步得到病理单模态 `0.695782`、未经校准固定融合 `0.697199`、训练折 ECDF 等权融合 `0.698837` 和正式 FICPF `0.705017` 的宏平均 C-index。FICPF 相对未经校准融合提高 `+0.007817`，95% CI 为 `[0.001065,0.015152]`，支持训练折尺度对齐的必要性。`alpha=0.10-0.30` 构成稳定平台，锁定的 `alpha=0.20` 继续作为主配置；虽然 `alpha=0.30` 在已观察测试集上的宏平均高 `0.000844`，但不据此进行事后替换。

1000 次组学打乱负对照显示，BLCA、GBMLGG、LUAD 和 UCEC 的真实患者级组学对应关系明显优于随机对应，BRCA 没有明确差异。完整消融、敏感性、打乱检验与审计见 `docs/FICPF组件消融与参数敏感性_20260821.md`。

固定运行时的 PCA 维数敏感性进一步得到 PCA16 `0.699804`、PCA32 `0.700360`、PCA64 `0.705320`、PCA128 `0.698368` 的宏平均 C-index。锁定的 PCA64 在统一重拟合中仍为最高。该敏感性运行与正式主结果存在 `+0.000303` 的宏平均数值依赖偏差，因此只用于维数趋势分析，不替换正式 FICPF 的 `0.705017`。
